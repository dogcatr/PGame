# DirectX12を使った3Dモデルの描画

本リポジトリでは、既存のDirectXコードを、正常に動作するように改修し、検証したプロジェクトを公開しています。

本プロジェクトの目的は、グラフィック処理の技術理解と、グラフィックライブラリへ依存しない描画手法の確立・検証です。

サンプルコードはバージョン違いのため、そのままでは動作しないという課題があり、全体的に最新(当時)のコードに改修しました。以下は主な作業です。

- API仕様変更への対応
- コンパイルエラーの解消

以下の本を参考にして、5.1のサンプルコードを元に制作しました。
[Direct3D12 ゲームグラフィックス実践ガイド](https://gihyo.jp/book/2021/978-4-297-12365-9)
